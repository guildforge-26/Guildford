# Executive OS - Project Rules

## Project
Build an AI-driven operating system that uses conversational onboarding to map mid-market business structures and automate executive review cadences.

## Tech Stack (Do Not Change Without Asking)
- **Language/Framework**: Python + Streamlit
- **Database**: SQLite (`sqlite3`)
- **AI SDK**: `google-genai` (Gemini API)
- **Hosting**: Streamlit Community Cloud

## Core Principles
1. Build only one feature at a time (Start with Feature 1: Conversational Onboarding).
2. Prefer the simplest solution that works (Python + Streamlit native components).
3. Never invent new libraries unless explicitly asked.
4. Always show clear error messages to the user in the UI.
5. Keep the design clean, professional, and executive-ready.
6. Before writing code, restate the acceptance criteria and confirm the plan.
7. After writing code, list exactly which files you changed and why.
8. Never commit secrets or API keys.

## File Scope
- Only create or edit files needed for the current feature.
- Never refactor unrelated code.
- Ask before changing database schema or adding new packages.

## When Unsure
- Stop and ask a clarifying question instead of guessing.
